# SpeedKlava 1.1.0

Тренажёр слепой печати для Windows с русской и английской раскладками, работающий без интернета.

## Новое для опытных

- Отдельный раздел «Для опытных», доступный без прохождения начального курса.
- Шесть режимов: скорость, ритм, сложные слова, персональные слабые пары, знаки и числа, программный код.
- Личная цель 100–800 знаков в минуту и занятия на 30/60/120/300 секунд.
- Оценка равномерности нажатий, отдельные рекорды и сравнение с последними результатами того же режима, языка и длительности.
- Достижение «Личный рубеж». Сохранена совместимость с прогрессом версии 1.0.

## Установка и обновление

1. Скачайте **SpeedKlava-Windows.zip** в разделе Assets ниже.
2. Распакуйте архив в обычную папку.
3. Запустите **SpeedKlava.exe**. Файл **SpeedKlava.exe.config** должен находиться рядом.

Требуются Windows 10/11 и .NET Framework 4.8. Системную раскладку Windows переключайте сочетанием Win + Пробел. Файл приложения не подписан цифровым сертификатом.

При обновлении замените exe и config. Прогресс хранится отдельно в `%LOCALAPPDATA%\SpeedKlava`; перед обновлением его можно экспортировать в настройках.

Научные источники и ограничения методики описаны в RESEARCH.md внутри архива и в разделе «Как это работает» программы.

Сборка выпуска выполняется только после проверок движка и автоматической проверки окна. SHA256SUMS.txt содержит контрольную сумму архива. Исходный код доступен через стандартные ссылки Source code ниже.
