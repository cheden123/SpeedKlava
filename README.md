# SpeedKlava

Нативный тренажёр слепой печати для Windows. Русский интерфейс, русская ЙЦУКЕН и английская QWERTY. Работает без интернета, регистрации и дополнительных пакетов.

**[Скачать готовую программу для Windows](https://github.com/cheden123/SpeedKlava/releases/latest/download/SpeedKlava-Windows.zip)** · [Все версии и изменения](https://github.com/cheden123/SpeedKlava/releases)

## Для тех, кто уже печатает вслепую · версия 1.1

Откройте **«Для опытных»** в левом меню. Полная раскладка доступна с первого запуска; проходить начальный курс или менять его этап не требуется. Подсказки пальцев в этом разделе скрыты.

| Режим | Что тренируется |
| --- | --- |
| Скорость | Поток частотных слов на всей раскладке RU/EN. |
| Ритм | Слова одинаковой длины; оценка равномерности последовательных нажатий. |
| Сложные слова | Длинные слова, редкие буквы и неудобные переходы. |
| Слабые пары | Слова с парами, на которых были ошибки или задержки, и короткое закрепление этих пар. При отсутствии статистики используются частые сочетания. |
| Знаки и числа | Даты, время, числа, заглавные буквы, кавычки и пунктуация. |
| Код | Фрагменты JavaScript, C#, HTML и CSS в одну строку; значимы регистр, знаки и пробелы. При выборе автоматически включается EN внутри приложения; системную раскладку переключите Win + Пробел. |

Выберите ориентир **100–800 зн/мин** и длительность **30/60/120/300 секунд**. Во время ввода видно отставание/опережение выбранного темпа в знаках. Это информационный ориентир: программа не пропускает символы и не заставляет печатать быстрее. Изменение режима, цели, раскладки или длительности завершает текущую попытку как прерванную.

Рекорд засчитывается за полную длительность при точности **≥97%**. После занятия результат сравнивается с медианой до пяти последних зачётных попыток **того же режима, языка и длительности**. Если таких результатов нет, программа предлагает создать первый ориентир. Пройденная цель получает достижение «Личный рубеж».

**Разброс ритма** — коэффициент вариации интервалов между последовательными верными нажатиями; меньше — равномернее. Он появляется после 10 подходящих интервалов. Ошибки и паузы разрывают последовательность, интервалы вне 20–3000 мс исключены. Сравнивайте показатель внутри одного режима: слова, пунктуация и код требуют разного ритма. Это описательная метрика, а не норматив и не самостоятельная оценка качества печати.

Прогресс версии 1.0 загружается автоматически. Новые поля добавлены в тот же формат XML; этапы начального курса сохраняются. Для обновления достаточно заменить exe и config, оставив прогресс на компьютере. Перед обновлением можно сделать экспорт в настройках.

## Запуск

1. Распакуйте `SpeedKlava-Windows.zip` в любую обычную папку.
2. Запустите `SpeedKlava.exe`. Рядом должен оставаться `SpeedKlava.exe.config`.
3. Выберите раскладку RU/EN, переключите раскладку Windows сочетанием Win + Пробел.
4. Нажмите «Начать практику». Отсчёт начинается с первого нажатия. Печатайте подсвеченный текст, смотрите на экран. Для паузы нажмите Esc.

Требования: Windows 10/11 с .NET Framework 4.8, обычная физическая клавиатура. На этом компьютере приложение собрано и прошло автоматическую проверку запуска WPF. Все конфигурации Windows и экранные дикторы отдельно не тестировались. Файл не подписан цифровым сертификатом.

## Возможности

- Восемь этапов от А/О или F/J до полного текста. Два последовательных занятия курса с ≥97% точности и ≥80 верных знаков открывают следующий этап; предыдущие этапы можно повторять.
- Адаптивная практика: вероятности букв зависят от ошибок, задержек и срока повторения. Режим слабых клавиш выбирает слова с трудными буквами; при отсутствии подходящих слов используются короткие группы букв.
- Отдельная тренировка буквенных пар. Подсказки пальцев учитывают физические клавиши и Shift в RU/EN. Карту клавиатуры можно скрыть.
- Полные тексты и контрольный тест доступны с первого дня. В тесте нет подсказок. Банк авторских текстов ограничен; порядок меняется. Тест не является стандартизированной диагностикой.
- 30/60/120/300 секунд — предельная длительность упражнения. Если текст закончился раньше, результат рассчитан по фактическому времени. Для опытных генерируется материал с запасом под всю длительность.
- Скорость в знаках в минуту и WPM (5 знаков); точность с учётом ошибочных нажатий. Исправление не удаляет ошибку из статистики. Ошибочная буква не двигает курсор: Backspace не требуется.
- Дневная цель 5–30 минут, XP, уровни, достижения, календарь практики, слабые буквы и история. Начальная цель — 10 минут; оптимальная длительность именно для этого тренажёра не установлена.
- Пауза при уходе из приложения и после 15 секунд без ввода. Эти 15 секунд входят в время упражнения; время явной паузы не входит. Удержание клавиши обрабатывается Windows как повторные нажатия.
- Незавершённые занятия сохраняют статистику и время, но не дают XP и не открывают этапы.
- Локальное сохранение, резервная копия, экспорт/импорт XML. Нет глобального перехвата клавиш, рекламы, телеметрии и загрузок из сети. Внешние ссылки открываются только по нажатию в разделе о методике.

Данные: `%LOCALAPPDATA%\SpeedKlava\progress.xml`, предыдущая версия — `progress.xml.bak`. Ошибка записи показывается в окне; до закрытия программы можно экспортировать данные. Аварийный журнал при ошибке запуска: `crash.log` в той же папке. Экспорт из настроек подходит для переноса на другой компьютер.

## Сборка из исходников

В PowerShell из корня исходников (папка `Source` в готовом архиве; корень проекта в репозитории):

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
.\bin\SpeedKlava.exe
```

Скрипт использует компилятор C# и WPF, поставляемые с .NET Framework. Не требует npm, NuGet, .NET SDK или сетевого доступа. C# 5; XAML встроен в exe как ресурс. Исходники находятся в `src/`.

`build.ps1` также запускает проверки движка: расчёты скорости и точности, ошибки и исправления, продвижение по курсу, разделение языков, генератор, интервалы, серии дней, сериализация и отклонение XML с внешними сущностями.

Изолированная проверка окна и снимки всех экранов (не изменяет профиль пользователя):

```powershell
.\bin\SpeedKlava.exe --smoke-test "$PWD\work\smoke"
```

`smoke-result.txt` содержит результат загрузки XAML, построения шести страниц и обработки тренировки, включая все режимы для опытных, переходы RU/EN, выбор цели и пяти минут, паузу и возврат к начальному курсу. Это автоматическая проверка, не замена ручного тестирования длительных занятий.

## Репозиторий

Код проекта: [cheden123/SpeedKlava](https://github.com/cheden123/SpeedKlava).

В [GitHub Actions](https://github.com/cheden123/SpeedKlava/actions/workflows/windows.yml) после изменений запускаются сборка Windows-приложения, проверки движка и автоматическая проверка окна. В успешном запуске скачайте артефакт `SpeedKlava-Windows`: он содержит exe, конфигурацию и документацию. Для скачивания артефактов может потребоваться вход в GitHub.

Готовые стабильные версии публикуются в **[Releases](https://github.com/cheden123/SpeedKlava/releases)**: архив `SpeedKlava-Windows.zip`, описание изменений и `SHA256SUMS.txt`. Они доступны без входа в GitHub и не имеют срока хранения артефактов Actions.

Для нового выпуска обновите `VERSION`, версию сборки в `src/App.cs` и добавьте `release-notes/vX.Y.Z.md`. После отправки изменения `VERSION` в `main` workflow `Publish Windows release` соберёт и проверит приложение, затем создаст тег и релиз. Также поддерживаются push тега `vX.Y.Z` и ручной запуск workflow; тег должен соответствовать `VERSION`. Уже опубликованные версии не перезаписываются. Для ручной команды тега: `git tag vX.Y.Z`, затем `git push origin vX.Y.Z`.

Проверки запуска окна в CI не заменяют тестирование на реальной клавиатуре и разных компьютерах. Для исходников используйте Code → Download ZIP или обычный git clone.
