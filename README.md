# SpeedKlava

Нативный тренажёр слепой печати для Windows. Русский интерфейс, русская ЙЦУКЕН и английская QWERTY. Работает без интернета, регистрации и дополнительных пакетов.

## Запуск

1. Распакуйте `SpeedKlava-Windows.zip` в любую обычную папку.
2. Запустите `SpeedKlava.exe`. Рядом должен оставаться `SpeedKlava.exe.config`.
3. Выберите раскладку RU/EN, переключите раскладку Windows сочетанием Win + Пробел.
4. Нажмите «Начать практику». Отсчёт начинается с первого нажатия. Печатайте подсвеченный текст, смотрите на экран. Для паузы нажмите Esc.

Требования: Windows 10/11 с .NET Framework 4.8, обычная физическая клавиатура. На этом компьютере приложение собрано и прошло автоматическую проверку запуска WPF. Все конфигурации Windows и экранные дикторы отдельно не тестировались. Файл не подписан цифровым сертификатом.

## Возможности

- Восемь этапов от А/О или F/J до полного текста. Два последовательных занятия курса с ≥97% точности и ≥80 верных знаков открывают следующий этап; предыдущие этапы можно повторять.
- Адаптивная практика: вероятности букв зависят от ошибок, задержек и срока повторения. Режим слабых клавиш выбирает слова с трудными буквами; при отсутствии подходящих слов используются короткие группы букв.
- Отдельная тренировка буквенных пар. Подсказки пальцев учитывают физические клавиши и Shift в RU/EN. Карту клавиатуры можно скрыть.
- Полные тексты и контрольный тест доступны с первого дня. В тесте нет подсказок. Банк авторских текстов ограничен; порядок меняется. Тест не является стандартизированной диагностикой.
- 30/60/120 секунд — предельная длительность упражнения. Если текст закончился раньше, результат рассчитан по фактическому времени.
- Скорость в знаках в минуту и WPM (5 знаков); точность с учётом ошибочных нажатий. Исправление не удаляет ошибку из статистики. Ошибочная буква не двигает курсор: Backspace не требуется.
- Дневная цель 5–30 минут, XP, уровни, достижения, календарь практики, слабые буквы и история. Начальная цель — 10 минут; оптимальная длительность именно для этого тренажёра не установлена.
- Пауза при уходе из приложения и после 15 секунд без ввода. Эти 15 секунд входят в время упражнения; время явной паузы не входит. Удержание клавиши обрабатывается Windows как повторные нажатия.
- Незавершённые занятия сохраняют статистику и время, но не дают XP и не открывают этапы.
- Локальное сохранение, резервная копия, экспорт/импорт XML. Нет глобального перехвата клавиш, рекламы, телеметрии и загрузок из сети. Внешние ссылки открываются только по нажатию в разделе о методике.

Данные: `%LOCALAPPDATA%\SpeedKlava\progress.xml`, предыдущая версия — `progress.xml.bak`. Ошибка записи показывается в окне; до закрытия программы можно экспортировать данные. Аварийный журнал при ошибке запуска: `crash.log` в той же папке. Экспорт из настроек подходит для переноса на другой компьютер.

## Сборка из исходников

В PowerShell из корня исходников (папка `Source` в готовом архиве; корень проекта в репозитории):

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
.\bin\SpeedKlava.exe
```

Скрипт использует компилятор C# и WPF, поставляемые с .NET Framework. Не требует npm, NuGet, .NET SDK или сетевого доступа. C# 5; XAML встроен в exe как ресурс. Исходники находятся в `src/`.

`build.ps1` также запускает проверки движка: расчёты скорости и точности, ошибки и исправления, продвижение по курсу, разделение языков, генератор, интервалы, серии дней, сериализация и отклонение XML с внешними сущностями.

Изолированная проверка окна и снимки всех экранов (не изменяет профиль пользователя):

```powershell
.\bin\SpeedKlava.exe --smoke-test "$PWD\work\smoke"
```

`smoke-result.txt` содержит результат загрузки XAML, построения страниц и обработки событий тренировки. Это автоматическая проверка, не замена ручного тестирования длительных занятий.
